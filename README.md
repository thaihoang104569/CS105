### Giới thiệu sơ lược về đồ án 

Đây là đồ án môn Đồ họa máy tính xây dựng một sân tập bắn súng 3D phong cách sci-fi bằng Three.js. Người chơi có thể di chuyển nhân vật, đổi góc nhìn camera, điều chỉnh ánh sáng, thay đổi texture sàn và bắn hạ các mục tiêu trong môi trường mô phỏng.

Project sử dụng các model FBX, texture hình ảnh và hiệu ứng ánh sáng động để tạo trải nghiệm trực quan hơn, đồng thời có HUD để điều khiển nhanh các thông số trong lúc chơi.


### Hướng dẫn chạy demo

1. Mở thư mục project bằng VS Code hoặc bất kỳ trình soạn thảo nào có hỗ trợ web server.
2. Chạy project bằng Live Server, hoặc một local server khác để tránh lỗi khi tải module ES và asset.
3. Mở trang web tại `index.html` qua địa chỉ của server, ví dụ `http://127.0.0.1:5500` hoặc `http://localhost:3000`.
4. Trong game, nhấn `1` để chuyển sang camera panoramic và `2` để chuyển sang camera third-person.
5. Dùng `WASD` để di chuyển, rê chuột để ngắm và click chuột để bắn.
6. Có thể đổi texture sàn, chỉnh camera, ánh sáng và bấm `Restart Game` để chơi lại từ đầu.
